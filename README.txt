Оранжевый Рассвет - обновлённая версия для самостоятельного размещения

Содержимое архива:
- index.html - главная страница сайта;
- robots.txt - правила для поисковых роботов;
- sitemap.xml - карта сайта.

Публикация на Cloudflare Pages:
1. Откройте свой существующий проект Cloudflare Pages.
2. Загрузите ZIP-архив этой версии через тот же способ Direct Upload / Drag and drop, которым публиковали сайт раньше.
3. Не удаляйте старый проект. Новая загрузка обновит содержимое существующего сайта.
4. После публикации откройте сайт на телефоне и проверьте форму заказа.
